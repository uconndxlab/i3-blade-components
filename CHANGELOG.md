# Changelog

All notable changes to `blade-components` will be documented in this file.

## [1.0.0] - 2026-05-05

### Added

- Initial tagged release with semantic versioning.
- `PoweredBy` Blade component.
- `UConnBanner` Blade component with framework-aware responsive breakpoints.
- Workbench component gallery and preview flow.
- Pest test suite, PHPStan analysis, and Pint formatting setup.

### Notes

- Composer consumers can now install stable versions using constraints like `^1.0.0`.
